# Marcos para NES Mini PC 0.6.0

Paquete de actualización con 872 pares de marcos laterales para la biblioteca NES de la versión 50. Junto con los 11 marcos incluidos en la 0.6.0, cubre 883 juegos. El catálogo identifica cada ROM por su SHA-256, por lo que puedes cambiarle el nombre y conservar su marco.

## Instalación

1. Cierra NES Mini PC 0.6.0.
2. Descarga el ZIP y extrae su carpeta `assets` sobre la carpeta de tu instalación.
3. Si personalizaste `assets/frames/temas.tsv`, combina las filas por identificador para conservar tus entradas.
4. Abre la app y activa **Marcos**. Los laterales se pueden usar en CRT, 4:3 y Píxel perfecto.

El paquete contiene gráficos y el catálogo. Las ROM se agregan por separado.
